# AI 활용 내역

AI를 기획·검토(Claude)와 구현·실행(OpenAI Codex)으로 나눠 활용했다. 단계 번호 ①~⑦은 보고서 2장의 단계 번호를 따른다.
판단 기준의 우선순위, 대안 선택, 가정 채택은 팀이 결정했고, AI는 설계안·판단 기준 초안·근거·선택지를 제시했다.

## 1. 도구와 역할

| 도구 | 활용 단계 | 활용 방식 |
| --- | --- | --- |
| Claude (Anthropic) | 전 단계 | 문제지 분석, 단계 설계안·판단 기준 초안 제시, 단계별 작업 지시서 작성, Codex 산출물 검토와 수치 교차 확인, 이상 결과 원인 분석(20분 반경 근거 부재, 비용 가중 편향 등), 보고서 초안, run_all.py·README·웹 시뮬레이터 연결(app/main.py, app_simple.py) 작성 |
| OpenAI Codex (GPT-6.1 Sol 기본, 일부 단계 GPT-6 Astra) | ①~⑦, 환류, 제출 양식 | 지시서에 따른 코드 구현, 시뮬레이션·최적화 실행, 검산표 생성, 작업 기록(docs/log.md) 작성 |

웹 시뮬레이터(app/main.py)의 화면 디자인과 기본 구조는 팀원이 구현했고, Claude가 시뮬레이션 환류(v3) 결과·보정값·필수 보고 지표를 연결했다.

## 3. 검산 기록 위치

- 단계별 작업 기록과 검산 결과: `docs/log.md`
- 데이터 결함·규칙·건수·처리: `outputs/data_issues_log.csv` (환류 대체 규칙 포함본 `data_issues_log_v3.csv`)
- 정제 검증: `outputs/clean_verification.md` · 재무 검증: `outputs/finance_verification.md`, `report/finance_check.xlsx`
- 네트워크 검증: `outputs/network_verification.csv`, `network_verification_D.csv`, `network_verification_v2.csv`, `network_verification_v3.csv`
- 배차 검증: `outputs/dispatch_verification.csv`, `dispatch_selected_verification.csv`
- 시뮬레이션 반경 실험 검증: `outputs/radius_bm_verification.csv`, `radius_bm_v2_repetitions.csv`

## 4. 작업 원칙

- 원본 데이터(`data/`)는 수정하지 않았다. 원본 파일의 SHA256 해시를 단계마다 대조했다.
- 결과 파일은 버전(_v2, _v3)으로 남기고 덮어쓰지 않았다. 최종본은 v3(`report/B_v3/`)이다.
- 각 단계는 결과와 함께 검산(재계산 일치, 해시 비교)을 남겼다.
- AI가 낸 수치는 Claude가 원자료와 교차 확인했고, 불일치는 다음 지시서에서 수정했다.
